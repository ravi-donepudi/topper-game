This repository implements a game in python with the following rules.

There is a 10x10 grid we are looking to cover with 2x2 squares. A covering is a placement of 2x2 squares such that every cell in the underlying grid is covered by at least one square.

A covering is called efficient if the removal of any square in its collection causes a cell to become uncovered.

Experiment with this to see what the largest efficient covering you can come up with!
